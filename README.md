# Facturi

Listă dublu înlănțuită cu facturi citite din fișier.

## Funcționalități

- citirea facturilor din `facturi.txt`
- traversarea în ambele sensuri
- totalul facturilor unui beneficiar
- modificarea sumei de plată a unei facturi
- ștergerea facturilor după un prag al zilelor până la scadență
- dezalocarea memoriei

## Structura de date

`factura`: număr, data emiterii, beneficiar, suma de plată, număr de zile până la scadență.

## Rulare

Se deschide `factura.sln` în Visual Studio. Fișierul `facturi.txt` trebuie să fie în directorul de lucru.
